## Overview

**LineageOS Info** is a focused, clean changelog reader for unofficial LineageOS builds (including Google Pixel 8a `akita` and Pixel 4 `flame`). Forked from [GrapheneOS Info](https://github.com/GrapheneOS/Info), this fork has been redesigned and rebranded:

- **Official LineageOS Branding:** Vector icons, adaptive launcher icons, and brand teal color scheme.
- **Dynamic Changelog Retrieval:** Fetches latest changelog entries directly from GitHub release notes and repository README files from the `Changes` section downwards.
- **Focused Experience:** Unnecessary community and donation tabs removed to provide a distraction-free, native changelog viewer.
- **Material 3 & Jetpack Compose:** Built with modern Android Jetpack Compose and Material 3 components.
